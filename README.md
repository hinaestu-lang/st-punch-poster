# repo 美化 · 发布文件

本目录只包含当前保留的插件和 CSS 模板，不包含被否定的旧稿、历史修订版或测试图片。

- `repo美化.json`：酒馆助手脚本，在酒馆助手中导入。
- `templates/`：19 份独立 CSS 模板，每个模板 ID 一份；JSON 不内置这些 CSS。

## 导入

1. 在酒馆助手中导入 `repo美化.json`。
2. 在插件「模板 → 导入 CSS」中按需导入 `templates/` 下的文件。
3. 重新导入同一个模板 ID 时，确认覆盖原来的旧版。

## 正文和收藏

- 划线、点句、整条消息、合并优先读取消息 DOM：`<br>` 为段内换行，`<p>` 等块元素为分段；连续 `<br><br>` 识别为空行。正文视觉软换行不被错误拆段。
- 新收藏直接保留原文中的段落空行，不再写入无实际渲染用途的 `paragraphFormat`，导入旧备份时也会移除该废弃字段。
- 源消息可用时，合并可使用 DOM 段落边界；离线时只信任带 `sourceParagraphFormat:2` 的段落位置，旧记录不会被强行猜测成分段。
- 离线合并无法确认段落时保留一个换行，不额外存储画布专用的软换行位置；打孔画布可能显示该换行，CSS 模板仍按收藏原文呈现。旧备份里的 `canvasSoftBreaks` 会在导入时移除。
- 已遗失 `<br>`／`<p>` 来源的旧收藏无法恢复精确段落信息，不会为每次旧换行强制增添段距。

## 划线交互优化

- 高频 `selectionchange` 仅验证选区所属消息与角色有效性，不再同步遍历正文 DOM；选区稳定 220ms 后才读取 DOM。
- 暂时收起的 Safari 选区使用预存 Range 恢复；取消、切聊天或划到消息外部会停止待执行操作。新的长按或双击可重新选择完全相同的文字，不会因旧的取消记录永久抑制菜单。
- 该优化通过 Chromium 模拟测试，尚未在 iPhone Safari 上完整验证。

## 兼容性与说明

- `essay_grid` 是脚本中的内部模板适配代码，本包没有格纸 CSS。
- 导出裁白色尾部仅针对已知场景的 iMessage、小红书评论页和脆个人主页，其余模板保留设计留白。
- 本轮通过 JavaScript 语法、JSON 解析、24 项针对性测试与 Chromium 模拟 DOM 测试；iPhone Safari 真机全流程、全部导出模式尚未验证。
- 公开发布前请确认字体、图标及设计素材的使用许可。
